# nalssam 패시브 인컴 콘텐츠 기획안 (2026-09)

> 검토용 초안입니다. 승인/수정 의견을 PR 코멘트로 남겨주세요.

## 왜 지금인가 — 이미 있는 자산

이 저장소에는 이미 세 가지 완성된 결과물이 있고, 전부 **AI 파이프라인(Claude + Higgsfield)으로 제작 비용을 낮춘 상태**입니다. 콘텐츠를 새로 판다기보다, 이미 만든 것을 다른 채널로 한 번 더 판매하는 데 가깝습니다.

| 자산 | 형태 | 재판매 가능성 |
|---|---|---|
| 6·25 전쟁 스토리텔링 방탈출 게임 | 웹 게임(브라우저) | 게임 자체 + 제작 과정 강의 |
| BlockQuest (AI 퀴즈 자동생성 + 3D 멀티플레이) | SaaS형 웹 앱 | 구독형 서비스 |
| 5-2-3 단원 페이퍼크래프트 · 비주얼싱킹 학습지 | 인쇄용 PDF | 학습지 마켓 판매 |

## 아이디어 1 — "선생님을 위한 AI 에듀테크 제작 마스터클래스"

**형태**: 영상 강의(6~8강) + 실습용 스타터 코드(GitHub 저장소) + 완성 예제(이 저장소의 방탈출 게임)

**판매 채널**
- **인프런(Inflearn)** — 메인 채널. 개발/생산성 카테고리에 "현직 교사가 만든 실전 예제"라는 차별점이 잘 먹히는 플랫폼
- **클래스101** — "직업+부업" 포지셔닝으로 노출, 비개발자 교사층 유입
- (선택) **Udemy 영문 버전** — "Build an AI-powered classroom game" 컨셉으로 해외 교사 대상 재활용

**타겟에게 매력적인 이유**
- 초등 교사는 몰입형 수업 자료 수요가 크지만 코딩 경험이 거의 없음
- 이 저장소의 두 프로젝트가 "실제로 학생들과 써먹은 완성품"이라는 신뢰 증거가 됨 (포트폴리오 = 강의 예고편)
- Claude Code / Claude API로 코드를 짜는 법을 알려주면 "나도 만들 수 있겠다"는 진입장벽 해소가 핵심 셀링포인트

**모듈(안)**
1. 기획: 교육과정 성취기준 → 스토리·퍼즐 설계로 바꾸기
2. AI로 삽화·배경음악·내레이션 영상 만들기 (Higgsfield류 툴)
3. Claude Code로 웹 게임 뼈대 코딩하기 (바이브 코딩 실습)
4. 무료 배포: GitHub Pages / Render 원클릭 배포
5. 실전 프로젝트: 6·25 전쟁 방탈출 게임을 처음부터 끝까지 재현
6. (심화) BlockQuest형 AI 퀴즈 자동생성 붙이기

## 아이디어 2 — 단원별 페이퍼크래프트·비주얼싱킹 학습지 세트 판매

**형태**: 프린트해서 바로 쓰는 PDF 번들(페이퍼크래프트 + 비주얼싱킹 학습지 + 교사용 지도안 1장)

**판매 채널**
- **아이스크림 자료실** — 가장 큰 초등 교사 자료 마켓, 업로드형 정산 구조라 완전한 패시브 채널
- **티처빌 자료실 / 인디스쿨 유료자료실** — 보조 채널로 동시 업로드해 노출 극대화
- (선택) **네이버 스마트스토어** — 세트를 묶어 직접 판매, 반응 좋으면 마진 더 큰 채널로 이전

**타겟에게 매력적인 이유**
- 5-2-2·5-2-3(일제강점기~6·25) 단원은 수업 준비 부담이 큰데, 이미 커리큘럼 성취기준에 맞춰 완성돼 있어 "바로 인쇄만 하면 되는" 자료
- 이미 만든 게임의 부산물(같은 단원, 같은 삽화 스타일)이라 별도 제작비 거의 없음

**구조(안)**
- 단원별 세트: [일제강점기] / [6·25 전쟁] / [대한민국 정부 수립] 등으로 시리즈화
- 세트 구성: 페이퍼크래프트 도안 + 비주얼싱킹 학습지 + 교사용 활용 가이드 1p
- 이후 5-2 전체 단원 → 6-1/6-2로 확장해 "초등 사회 완결 시리즈"로 브랜딩

## 아이디어 3 — BlockQuest 구독형 서비스

**형태**: 지금은 Render에 교사가 직접 배포해야 전체 기능(AI 퀴즈 생성 등)을 쓸 수 있음 → nalssam이 직접 호스팅해 **월 구독**으로 전환

**판매 채널**
- 자체 사이트(현재 배포 인프라 그대로 활용) + 토스페이먼츠/아임포트 결제 연동
- 아이디어 1의 마스터클래스 수강생에게 "직접 만들기 vs 그냥 구독" 업셀 옵션으로 교차 판매

**타겟에게 매력적인 이유**
- Kahoot류 서비스와 달리 **자기 수업 자료(PPT/PDF)를 업로드하면 AI가 퀴즈를 자동 생성**하는 게 핵심 차별점
- 3D 멀티플레이 월드는 카훗 계열에 없는 몰입 요소 — 캡처 영상 하나로 바이럴 가능성 있음

**요금제(안)**
- 무료: 학급 1개, 문항 자동생성 회당 제한
- 유료(월 구독): 무제한 학급, AI 퀴즈 무제한 생성, 인사이트 리포트 저장

## 수익화·자동화 전략 요약

1. **콘텐츠 재사용 극대화**: 같은 삽화/영상 자산을 게임 → 강의 예제 → 학습지 세 갈래로 재판매 (제작은 1회, 판매 채널은 다수)
2. **플랫폼 다각화**: 자료실형(아이스크림) + 강의형(인프런/클래스101) + 구독형(자체 SaaS)을 동시에 굴려 한 채널 의존도를 낮춤
3. **퍼널 설계**: 학습지 구매자 → BlockQuest 체험 유도 → 마스터클래스 업셀. 반대 방향(강의 수강생 → 구독 결제)도 가능
4. **콘텐츠 플라이휠**: 이미 구축된 Claude+Higgsfield 파이프라인으로 5-2 나머지 단원, 6-1/6-2 단원까지 낮은 한계비용으로 확장 → 자료실 시리즈가 스스로 늘어나는 구조

가장 마진이 크고 착수 리드타임이 짧은 순서로:

1. **아이디어 2 (학습지 판매)** — 이미 완성된 자산을 업로드만 하면 됨, 1주 내 착수 가능
2. **아이디어 1 (마스터클래스)** — 촬영·편집 필요, 2~4주 소요되지만 단가가 가장 높음
3. **아이디어 3 (BlockQuest 구독)** — 결제/과금 인프라 추가 개발 필요, 중기 과제로 분류
