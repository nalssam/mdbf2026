## 아이디어 1 — "역사가 살아있는 방탈출 수업 만들기" 교원 연수·마스터클래스

- **제품**: 교사가 직접 몰입형 스토리텔링 방탈출 수업을 만드는 법을 가르치는 강의. mdbf2026의 6·25 방탈출 게임을 실제 사례·템플릿으로 제공.
- **플랫폼**:
  - 티처빌/아이스크림 원격교육연수원 — 직무연수 학점 인정과정으로 등록하면 교사들에게 강한 유인 제공
  - 클래스101 — 일반 대상(홈스쿨링 부모, 사교육 강사 등)으로 확장
- **타겟 매력 포인트**: 교사들은 "몰입감 있는 자료가 필요하지만 만들 시간·기술이 없다"는 공통된 어려움이 있음. 이미 완성된 템플릿과 AI 도구 사용법을 그대로 넘겨주는 방식이라 실습 성공률이 높음.
- **구성(4모듈)**:
  1. 학습목표 → 방탈출 스토리 설계 프레임워크
  2. Higgsfield로 삽화·음악·영상 제작 실습
  3. 노코드 HTML 템플릿에 콘텐츠 얹기 (코딩 지식 불필요)
  4. GitHub Pages 무료 배포 + QR 학생 접속 + 저작권/안전 고려사항

**상태: 제안됨(검토 대기)**

## 아이디어 2 — BlockQuest 학급 구독 서비스 (SaaS)

- **제품**: BlockQuest를 호스팅형 구독 서비스로 전환. 교사는 서버/Supabase 설정 없이 월/연 구독만으로 자기 학급 코드(3D 멀티플레이 퀴즈 월드 + AI 퀴즈 자동생성)를 받음.
- **플랫폼**: 자체 웹사이트(Render/Vercel 배포, 토스페이먼츠/Stripe 결제), 인디스쿨 공동구매 형태로 초기 홍보.
- **타겟 매력 포인트**: 매 학기 새 학급에 반복 사용되는 구조라 자연스러운 재구독 유인이 있고, 서버 세팅 부담을 없애는 것이 핵심 가치.
- **요금 구조(안)**:
  - Free: 학급 1개, 규칙 기반 퀴즈 생성만, 워터마크 포함
  - Basic(월 구독): AI 퀴즈 자동생성 포함, 무제한 퀴즈 세트
  - Pro(연 구독): 다학급/부서 단위, 인사이트 대시보드, 커스텀 월드 테마

**상태: 제안됨(검토 대기)**

## 아이디어 3 — 디지털 다운로드 학습자료 팩 (비주얼싱킹 + 페이퍼크래프트)

- **제품**: 기존 비주얼싱킹 학습지 + 페이퍼크래프트 디오라마를 단원별 세트로 묶어 PDF 다운로드 상품화. 5-2-2, 5-2-3 단원부터 시작해 점차 확장.
- **플랫폼**: 아이스크림 마켓, T-Selfie, 인디스쿨(자료 공유+후원) — 국내용. Gumroad·Etsy — 영문 번역판으로 해외 홈스쿨링/역사교사 시장 공략(한국전쟁 페이퍼크래프트는 Etsy에서 희소성 있는 니치).
- **타겟 매력 포인트**: 이미 제작된 자산이라 추가 제작비 거의 0. 즉시 다운로드 + 저가 정책으로 판매량 확보.
- **구성(안)**: 단원별 세트 = 비주얼싱킹 학습지 12종 + 방탈출 스토리 카드 + 디오라마 도안 3종. 국내 3,000~8,000원, 해외 $4~9.

**상태: 제안됨(검토 대기)**

## 수익화·자동화 전략

| 아이디어 | 수익 모델 | 자동화 포인트 |
|---|---|---|
| 1. 마스터클래스 | 1회성 수강료 + 플랫폼 수익분배 | 사전 녹화 영상, 연수원/클래스101이 결제·수료증 처리 |
| 2. BlockQuest SaaS | 월/연 구독(recurring) | 결제 게이트만 추가하면 됨(교사용 프로비저닝 흐름은 이미 구현됨) |
| 3. 디지털 다운로드 팩 | 1회성 구매 | 업로드 후 자동 다운로드 링크 발급(아이스크림마켓/Gumroad/Etsy가 처리), 업로드 이후엔 손이 거의 안 감 |

**추천 착수 순서**: 아이디어 3(가장 빠름, 이미 있는 자산 재활용) → 판매·인지도로 오디언스 확보 → 아이디어 1(마스터클래스)로 수요 검증 → 검증되면 아이디어 2(SaaS)로 반복 수익 구조 확장.

**참고**: 아이디어 2(구독형)와 아이디어 1(연수원 강좌)처럼 지속적·정기적 소득이 발생하는 형태는 공무원(교원) 겸직허가 대상일 수 있습니다. 진행 전 소속 학교/교육청의 겸직허가 절차를 확인하는 것을 권장합니다.
